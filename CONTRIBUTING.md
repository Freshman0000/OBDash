# Contributing to OBDash 🏎️💨

First off, thank you for considering contributing to OBDash! 

**A quick note from the creator:** I am a first-time app designer and I built this entirely using AI because no one else was making this specific, high-end style of app that I was looking for. Because I'm so new to this, **I really need your help and input!** I'm looking for feedback on how to make the app more robust, improve the codebase, and add in features that I might not have even thought of yet.

Whether you're a seasoned dev testing it in your daily driver, hitting the track, or designing custom gauge skins, your feedback and contributions are what will make this project thrive.

## 💬 We Want Your Feedback

We are constantly looking to improve OBDash, and your real-world experience is invaluable. 

- **Bug Reports:** Is a gauge needle sticking? Is the OBD2 data lagging? Let us know by opening an issue.
- **Feature Requests:** Want a new dashcam integration, a specific vehicle's gauge layout, or a new telemetry PID? We'd love to hear about it!
- **Show off your setup:** Share photos of OBDash running in your carputer or head unit rig!

## 🛠️ How to Contribute

### 1. Reporting Bugs
When logging a bug, please include:
- Your device and operating system (Android Head Unit, Raspberry Pi, Tablet, etc.)
- The OBD2 adapter you are using (e.g., OBDLink MX+, generic ELM327)
- Steps to reproduce the issue
- Screenshots or video if applicable

### 2. Suggesting Enhancements
When suggesting a new feature:
- Describe the feature in detail.
- Explain how it would benefit track day drivers, daily commuters, or project car builders.
- If suggesting a new skin, providing mockup images or references to real-world gauge clusters is highly appreciated!

### 3. Submitting Pull Requests
If you want to get your hands dirty with the code:
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-new-gauge`).
3. Make your changes (ensure you follow the existing React/Tailwind patterns).
4. Commit your changes (`git commit -m 'Add an amazing new gauge'`).
5. Push to the branch (`git push origin feature/amazing-new-gauge`).
6. Open a Pull Request!

## 🎨 Creating Custom Skins
If you've designed a new gauge cluster skin, we want to see it! Please submit a PR adding your component to the `/components` directory and updating the `SkinDesigner` list. Be sure to include a screenshot of your skin in the PR description.
